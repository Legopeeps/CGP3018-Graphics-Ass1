# CGP3018 Graphics – Assessment 1

**Student ID:** 25788983

**Module:** CGP3018 Graphics

## Project Overview

This repository contains the Unreal Engine grey-boxed level prototype developed for Assessment 1. The project translates architectural and level plans into a playable 3D environment, focusing on spatial flow, sightlines, scaling, and Blueprint-driven puzzle mechanics.

## Features & Mechanics

* **Level Grey Box:** Full playable blockout constructed to scale based on the provided level and building plans.

* **Blueprint Puzzle System:** Interactive puzzle mechanics (e.g., weighted cube triggers to reveal path) built using Unreal Engine Blueprints.
